# Security

Orbit is early-access software. Use the latest release; older versions do not have a guaranteed security-maintenance window. Ad-hoc signing is not notarization, and automated tests do not prove every installed-device permission or capture behavior.

Do not include exploit details, credentials, private logs or recordings in public issues. If the repository's Security tab offers **Report a vulnerability**, use that private channel. If it is not available, the maintainer must enable private reporting before receiving details. No dedicated security email or response-time guarantee is currently published.

For ordinary bugs, use the bug report form with redacted diagnostics. See [data handling](docs/PRIVACY.md) for network requests, local files and password handling.
