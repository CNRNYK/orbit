# Changelog

## 0.19.1

- Combine screenshot and recording shortcuts in one menu-bar Screen Capture card with a shared mode selector.
- Start recording directly from the selected mode, with window selection available in the menu and floating pause/stop controls.
- Remove update, health-check and operation-log shortcuts from the menu; keep them in the main app.

## 0.19.0

- Unified Discover search, deduplicating recommended and official Homebrew results.
- Library combines installed apps and saved favorites with All/Installed/Saved filters.
- Reviewed manual application removal and exact matching leftover cleanup to Trash.
- Automatic unique recording destinations; finalized recordings open preview.
- Keep or remove a selected video interval, exporting a new copy with retained audio.
- Menu bar screenshots for full screen, area and window; captures open the editor.
- Icon annotation toolbar with selected states and accessibility labels.
- Setup Center unifies requirements, permissions and Orbit startup preferences.
- Login apps load automatically with existing access; Add application starts in Applications.
- Feature folders, grouped tests, contributor documentation and refreshed app screenshots.

Delivered through PRs #23, #24 and #25. No automatic user-file cleanup or permission bypass.

## 0.18.0

Homebrew Center consolidated app browsing, installation, updates and saved favorites; installation and removal selections were separated (PR #22).

## 0.17.0

Permission Center, App Health Check, Login Items, live recording annotations, visible capture border and Screenshot Studio (PR #21).

## 0.16.1–0.16.3

Native playback fixed the completed-recording preview crash; compact recording controls and menu layout improved; ScreenCaptureKit became the authority for source access (PRs #18–#20).

## Earlier milestones

- Screen recording, video effects and menu controls (PR #17).
- Persistent menu bar access and window reopening (PR #16).
- Clearer selections, cleanup bulk actions and operation diagnostics (PR #15).
- Backup-aware developer terminal profiles (PR #14).
- Orbit identity, logo and DMG distribution (PRs #12–#13).
- Inline cleanup, official Homebrew discovery and saved apps (PR #10).
- Reviewed install/update/removal, app adoption, Brewfile reuse and bundled official icon catalog underpin these features.

For detailed historical behavior, see [FEATURES.md](FEATURES.md). The current README describes the latest release.
