# Asset provenance

Orbit's branding is stored in Resources/Branding. Application icons in Resources/Logos belong to their respective vendors or projects and are used to identify catalog entries. Catalog records include logoURL, logoSource and logoAsset fields; those URLs identify the original source, not a license grant.

The MIT source license does not relicense third-party icons, product names or trademarks. Vendor-specific usage and redistribution terms have not been individually cleared by the publication-readiness check. Preserve attribution/source metadata and review applicable terms before broader distribution. If an asset needs replacement or removal, submit a focused change that retains a generic icon fallback.

README screenshots are app-rendered demonstration fixtures. They are not captures of user applications, private recordings or cleanup results. The development/release guides describe how to regenerate them.
